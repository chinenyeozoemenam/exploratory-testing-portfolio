# Gmail Login Test Execution Report

## 1. Project Overview

This report documents the results of the manual testing carried out on the Gmail login page.

The purpose of the testing was to verify that the Gmail login functionality behaves as expected under different conditions, including valid login details, invalid login details, empty fields, special characters, and other test scenarios.

Testing was performed manually using Google Chrome, while Microsoft Excel was used to document test cases and record test results.

   ## 4. Test Coverage

The following areas of the Gmail login functionality were covered during testing:

- **Valid Login:** Testing login with correct email and password.
- **Invalid Login:** Testing login with incorrect email or password.
- **Empty Fields:** Checking how the system responds when required fields are left empty.
- **Special Characters:** Testing inputs containing special characters.
- **Long Text Inputs:** Checking how the system handles unusually long inputs.
- **Security Inputs:** Checking how the login page responds to SQL injection test inputs.
- **Password Recovery:** Testing the password reset process.
- **Remember Me:** Checking the remember-me functionality where available.
- **Multi-Device Testing:** Checking login behaviour across different devices.

The test cases were executed to verify that the application responded according to the expected results.
